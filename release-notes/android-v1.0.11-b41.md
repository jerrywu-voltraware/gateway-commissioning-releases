# Android 1.0.11 (Build 41)

補齊最後 iOS／共用來源中的 Wi-Fi 與畫面調整，修正 Build 40 未包含這批修改的問題。

- Wi-Fi 設定使用「使用手機目前的 Wi-Fi」帶入名稱，再自行輸入密碼；保留手動輸入，不再顯示掃描其他 Wi-Fi 的入口。
- 保留最新近期資料頁、直連 PTU 挑選與完成頁調整，以及閘道器已連線標籤的對齊。
- 保留權限拒絕時的手動備援、切換不同網路清除舊密碼、晚到讀取結果防護與原有斷線續作流程。

驗證：1,543 項 Flutter 測試通過、靜態分析無問題；另有 100 項獨立專項通過。正式簽章、SDK28 簽章相容性校驗、16K 對齊、三 ABI 的來源與 Wi-Fi 內容及完整 APK 雜湊均已獨立核對。

本版尚未進行真實手機的 SSID／BLE／PTU 配置驗收，不宣稱 Android 133 問題已根治。本輪僅發布 Android，沒有 iOS 建置或上傳。更新前請完成或取消進行中的配置／暫時 PTU 換綁。

版本固定 1.0.11，Build 增加至 41。來源：63688a7c29bf59e4176b57982f026691b055dd20。已公開的 Build 40 保留原始資產。
