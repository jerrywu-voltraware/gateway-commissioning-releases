# GIOS 設備助手 1.0.11（Build 50）

- 手機桌面名稱與 App 頂部標題統一為「GIOS 設備助手」。
- 加入下一步操作引導：小箭頭與金黃色粗體提示柔和閃爍，連線或操作中暫停提示。
- 站點選擇同時提示「使用此站點」與「改用其他站號」，讓兩個選項更清楚。
- 重設 Wi-Fi 後顯示等待上傳的進度，避免在正常等待期間先出現紅字。
- 保留手機目前 Wi-Fi 帶入、APP 記住密碼與顯示／隱藏密碼功能。

本版沿用已安裝到現場手機的同一顆正式簽章 APK。依使用者要求，本輪未執行功能測試；發布時核對版本、簽章、下載檔案與更新通道。iOS 名稱設定已同步到原始碼，本次發布僅包含 Android。
