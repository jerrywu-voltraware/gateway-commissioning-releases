# GIOS 設備助手 1.0.11 Build 53

- 「查看上傳資料」的電流改為顯示接收端輸出電流（PRU IOUT），不再以發射端輸入電流代替。
- 發射端溫度與接收端溫度分開顯示，並新增效率與接收端 MAC。
- 裝置錯誤碼會顯示對應的說明（共 19 種）；不在清單內的代碼標示為「未知錯誤」。
- 頁首標題改為單行完整顯示、不再縮小；「請後台協助」與環境切換按鈕移到標題下方第二列。
- 需搭配後台 v1.37.0；後台尚未更新時，新增欄位會顯示「--」。
- 已知問題：小螢幕或大字體時，部分頁面需向下捲動才看得到下方內容；英文介面的最近資料表頭（例如 Transmitter temp）可能被截斷。

請在 APP 右上角選單點選「檢查更新」安裝。既有設定與記住的 Wi-Fi 密碼會保留。
