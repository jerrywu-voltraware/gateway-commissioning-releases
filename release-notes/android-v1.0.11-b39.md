Android 1.0.11（Build 39）

- 版本號維持 1.0.11，整合昨晚的 APP 修改並將 Build 升為 39。
- 調整藍牙連線與清理順序，分開選取、連線和開始開通；取消及重連狀態更清楚。
- 搜尋／停止按鈕固定於底部，開通操作移到對應閘道器卡片。
- 改善後台離線、尚未登記與找不到已綁定 PTU 的說明。
- 修正只重設 Wi-Fi 流程中的 PTU 更換判斷，加入換綁恢復紀錄、裝置身分核對與設定讀回。
- 辨識秒數依 PTU 規格限制為 0 或 2–10 秒，預設 4 秒。

更新前請先完成或取消正在進行的配置／PTU 更換。藍牙連線仍可能出現中間重試；本次發布不代表所有 Android 133 或實體換綁情境均已驗收。
