# Android 1.0.11 (Build 42)

Wi-Fi 設定新增記住密碼、自動帶入，以及眼睛顯示／隱藏。

- 首次在 APP 輸入密碼，勾選「記住密碼」並確認設定成功後保存；下次同一個 Wi-Fi 名稱可自動帶入，仍可修改。
- 可取消記住或忘記已存密碼；失敗、取消或未使用本次密碼時不保存。忘記可作廢尚未完成的舊提交，晚到讀取也不會覆蓋使用者輸入。
- 密碼預設遮蔽；離開 APP、切換網路或送出時恢復遮蔽。密碼透過平台安全儲存，Android 備份／裝置轉移排除對應憑證檔案，iOS 儲存設定限本機且不同步。
- 保留 Build 41 的手機目前 Wi-Fi／手動輸入流程及共用畫面調整；沒有讀取手機系統保存的 Wi-Fi 密碼。

驗證：1,575 項 Flutter 測試通過、靜態分析無問題；58 項獨立專項通過。正式 APK 的版本、簽章、SDK28 簽章相容性校驗、16K 對齊、備份規則資源與完整雜湊均已獨立核對。

本版尚未完成實機安全儲存、備份還原／裝置轉移、iOS Keychain 或 BLE／PTU 配置驗收。本輪僅發布 Android，沒有安裝手機或建置／上傳 iOS。更新前請完成或取消進行中的配置／暫時 PTU 換綁。
